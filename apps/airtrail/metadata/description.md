# AirTrail

AirTrail is a modern, open-source personal flight tracking system that lets you log and explore your entire aviation history.

## Features

- **Interactive world map** — visualize all your flights with route lines and frequency-based color coding
- **Flight statistics** — total distance, time in the air, airports visited, and more
- **Multi-user support** — share an instance with family or friends, each with their own history
- **Flight import** — import from MyFlightRadar24, Flighty, App in the Air, JetLog, TripIt, and byAir
- **OAuth support** — sign in with external identity providers
- **Dark mode** — full dark mode support across the UI
- **Responsive design** — works on desktop and mobile browsers
