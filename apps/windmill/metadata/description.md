Windmill is an open-source developer platform for building internal tools. Write scripts in Python, TypeScript, Go, Bash, SQL, or Rust, and Windmill automatically turns them into sharable UIs, webhooks, scheduled jobs, and HTTP endpoints. Compose scripts into workflows via a drag-and-drop editor, build rich low-code apps on top, and trigger everything from schedules, webhooks, Kafka, or email.

## Features

- **Multi-language support**: Python, TypeScript, Go, Bash, SQL, GraphQL, Rust, and more
- **Auto-generated UIs**: Script parameters are automatically parsed into frontend forms
- **Workflow engine**: Visual flow editor to chain scripts together (13x faster than Airflow)
- **Low-code apps**: Drag-and-drop app builder on top of scripts and flows
- **Triggers**: Schedules, webhooks, HTTP routes, Kafka, WebSockets, and email
- **Self-hosted**: Full data control with PostgreSQL backend
- **SSO/OAuth**: Google Workspace, Microsoft/Azure, Okta, and OpenID Connect

Windmill is a self-hosted alternative to Retool, Pipedream, Superblocks, and Temporal.
