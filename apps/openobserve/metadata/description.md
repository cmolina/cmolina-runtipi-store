OpenObserve is a cloud-native observability platform built in Rust for logs, metrics, traces, dashboards, alerts, and real user monitoring (RUM).

## Features

- Unified UI for logs, metrics, traces, dashboards, alerts, and incidents
- Parquet columnar storage — up to 140x lower storage cost than Elasticsearch
- Full-text search and SQL queries over your data
- Single binary with embedded SQLite — no separate database required
- OpenTelemetry-native ingestion for logs, metrics, and traces
- Self-hosted and privacy-friendly — your data stays on your server
